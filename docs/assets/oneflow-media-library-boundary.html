OneFlow × media-library · phân tích tích hợp 19/08/2026

Ranh giới hai hệ

Media-library không render video — OneFlow là máy render nó từ chối xây. OneFlow cần kho footage — media-library là kho đó, đã chạy, quy hoạch đa lĩnh vực (BĐS → tài chính, bảo hiểm…). Mọi điểm nối đi qua REST + API key với tám bảo đảm ranh giới của ADR-0012; không bên nào đổi kiến trúc. Nét đứt magenta đã được ADR-0012 chốt cơ chế — chưa thi công; thứ còn mở ở Gate G0 chỉ là chọn gói lĩnh vực.

Node nạp từ kho

Search → chọn thẻ → URL ký → bytes về kho file thành file_key. Add node không ABI-driven nên không đụng ABI, không kéo SDK release train. Làm được trước G0; key nằm trong kho khoá BYO sẵn có.

Giai đoạn C · tri thức — ADR-0012

Uỷ quyền KG — đã chốt

tasks.entity_refs trỏ entity_id của library thay vì xây bảng entities riêng (Phase 1.7) — không nguồn sự thật thứ hai. Lĩnh vực là dữ liệu, không phải code: library mở sang tài chính/bảo hiểm thì OneFlow thừa hưởng bằng 0 dòng code. Điều kiện thoát ghi trong ADR: G0 chốt ngách mà library chưa có gói lĩnh vực đó → kho tối thiểu cục bộ (file_key + tag phẳng, không KG).
